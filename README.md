BMI Calculator App - BMIcal

An Android application built using Kotlin to calculate Body Mass Index (BMI) based on user input of weight and height.

📱 Features

- Enter weight (kg) and height (cm)
- Automatically calculate BMI
- Show result with BMI category (Underweight, Normal, Overweight, Obese)
- Simple and clean UI
- Instant feedback

🛠 Built With

- Android Studio
- Kotlin
- ViewBinding 

🚀 Getting Started

Prerequisites
- Android Studio installed
- Android SDK version 30+
- Kotlin support enabled
